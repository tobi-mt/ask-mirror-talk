# Mirror Talk Theme 6.5.0

## Intelligent, calm featured conversations

- Autoplay now adapts its dwell time to the amount of text in each featured conversation.
- A visible progress line communicates timing without visual noise.
- Visitors can pause or resume the slider, use previous/next controls, or swipe horizontally.
- Animation stops while the slider is off-screen, the tab is hidden, hovered, or keyboard-focused.
- `prefers-reduced-motion` disables autoplay and transition movement.

## Privacy-first personalisation

- Returning visitors receive a restrained time-aware welcome.
- Topic selections and topic-hub visits build a small affinity profile stored only in that browser.
- The slider can begin with a featured conversation matching the visitor's strongest topic affinity.
- No precise geolocation, IP targeting, fingerprinting, third-party profile, or network transmission is used.
- Search engines and first-time visitors continue to receive the same stable server-rendered content and links.

## Deployment

Upload and activate `astra-child-v6.5.0.zip`, then purge WordPress/page/CDN caches. The service-worker cache version is `amt-v6.5.0`.
