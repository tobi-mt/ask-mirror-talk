# Mirror Talk Theme 7.6.1 — Intentional Navigation

The primary navigation now presents one clear path for each visitor intention.

- Renames the podcast archive parent from **Blog** to **Listen**.
- Keeps **Insights** inside **Ask Mirror Talk** when the editor has already nested it.
- Prevents the theme from manufacturing a duplicate top-level Insights item.
- Places a missing Insights item under Ask Mirror Talk automatically when possible.
- Removes the separate Astra **Join Us** header button because it duplicated **Connect** and pointed to the same Contact page.
- Applies the same hierarchy to desktop and mobile navigation through the shared WordPress menu filter.

Resulting primary flow: **Home → Listen → Ask Mirror Talk → Connect**, with **Insights** available inside Ask Mirror Talk. Existing curated submenu resources remain available under Listen.
