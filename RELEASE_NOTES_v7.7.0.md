# Mirror Talk Theme 7.7.0 — Fully Owned Experience

Mirror Talk now owns the global public experience instead of inheriting Astra's visible header, footer and fallback pages.

- Native Mirror Talk header and brand treatment.
- Accessible desktop dropdowns and mobile navigation.
- One listener-first hierarchy shared across templates.
- Native editorial footer with listening, reflection, connection and podcast-platform paths.
- Explicit privacy/safety language in the footer.
- Mirror Talk search-results and 404 templates.
- Existing owned homepage, standard page, post, Blog, category, tag, author, date, topic and Insights templates now share the same shell.
- Preserves `wp_head`, `wp_body_open`, `wp_footer`, custom logo, WordPress menus and plugin compatibility.
- Astra remains installed only as the required parent compatibility layer; its public header/footer markup is no longer used.

The release was designed as a structural replacement, not a layer of CSS hiding inherited components.
