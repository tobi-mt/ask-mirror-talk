# Mirror Talk Theme 8.0.0 — Autonomous Intelligence & SEO Platform

This release turns the existing native SEO layer into a governed, self-starting platform while preserving the website's visual experience and performance.

## Works immediately

- Automatic IndexNow queueing and batched submission on publishing, updating and deletion.
- Dedicated Google News and video sitemaps alongside the complete image-aware sitemap.
- Public `/llms.txt` with explicit public/private usage boundaries.
- RSS source attribution.
- Protected robots.txt additions with all sitemap declarations retained.
- Automatic old-slug redirects plus a native redirect manager and hit counts.
- A scheduled, rate-limited full-site link crawler and broken-link report.
- SEO metadata revision history and one-click rollback.
- Protected SEO REST fields and a dedicated SEO Manager role/capability.
- Advanced author expertise, credentials and profile links in Person/Article schema.
- Conservative, factual Media Library alt-text repair.
- Zero-configuration editorial scoring, metadata suggestions, internal-link guidance and browser spellchecking.
- Conditional WooCommerce Product/Offer schema.
- Opt-in LocalBusiness schema that refuses to invent an address.
- A consolidated Mirror Talk SEO control centre.

## Connect once, then automatic

- Google Search Console and Bing Webmaster synchronization endpoints and schedules.
- Google, Bing and Pinterest site verification.
- Verified keyword position reporting from webmaster data rather than brittle or prohibited search-result scraping.
- Provider-authorized AI enhancement and AI-search citation monitoring hooks.

External platforms require the account owner to grant access at least once. Version 8.0.0 intentionally does not counterfeit OAuth consent, silently transmit private content, spend third-party API credits, or manufacture local-business facts.

## Quality assurance

- 179 automated tests pass; 3 are intentionally skipped.
- Five pre-existing pytest warnings concern older tests that return booleans instead of asserting.
- Private Ask Mirror Talk reflections remain excluded from sitemaps, feeds, public analytics and editorial AI workflows.
