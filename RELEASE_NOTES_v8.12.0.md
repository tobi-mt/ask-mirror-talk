# Mirror Talk 8.12.0 — Guided Story Studio

- Adds a guided Story Studio to every post and page editor.
- Keeps WordPress title, content, featured image, author and publication schedule as the protected source of truth.
- Lets editors select an RSS episode or automatically use the latest available episode.
- Lets editors supply a YouTube or Shorts URL or automatically use the latest channel upload.
- Places the listening moment after editorial context and the visual moment deeper in the story.
- Adds reversible podcast-follow and direct newsletter invitations after the reader receives value.
- Uses privacy-enhanced YouTube embeds loaded only after an explicit click.
- Uses the first-party featured image or a branded gradient as the video poster, avoiding a YouTube thumbnail request before consent.
- Adds podcast and video relationships to structured data where valid.
- Tracks inline podcast and video engagement in Mirror Talk Intelligence.
- Adds Composer controls for every new module and includes Story Studio settings in rollback snapshots.
- Protects existing published content: legacy posts opt in explicitly, while new drafts start with Story Studio enabled.
- Keeps all feed lookups off the reader request path by using cached last-good media and scheduled refreshes.
