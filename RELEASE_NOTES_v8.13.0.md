# Mirror Talk 8.13.0 — Guarded Taxonomy Intelligence

- Adds automatic category and tag assignment to the background Editorial Composer workflow.
- Assigns categories only from an administrator-approved set of already-existing categories.
- Requires high-confidence, unambiguous topic evidence before adding a category.
- Preserves all editor-owned category and tag choices.
- Removes `Uncategorized` only when a strong approved category is safely assigned.
- Creates at most five distinct, evidence-backed tags from verified guests, expertise, books/resources, named concepts, existing terms present in the source, and eligible verified search queries.
- Rejects generic, spam-like, excessively long and near-duplicate tags.
- Re-evaluates taxonomy after verified Google/Bing keyword evidence changes.
- Records Composer-owned terms, evidence and change events in the Composer report.
- Provides individual removal controls, persistent exclusions and taxonomy-state rollback.
- Adds a Taxonomy governance screen for approving eligible existing categories.
- Adds verified books/resources and named-concepts fields to the Knowledge & Trust panel; neither is inferred or invented.
