# Mirror Talk Theme 8.4.1

This is the hardened SEO-learning build following live 8.4.0 verification.

- Protects an existing manually authored SEO title from automatic experimentation.
- Detects an editor or REST title change during an experiment, ends that experiment and preserves the editor's value.
- Prevents pause or automatic rollback from overwriting a later human edit.
- Handles removed posts without attempting title evaluation.
- Weights average query position by impressions.
- Retains all 8.4.0 focus-keyword learning, evidence thresholds, statistical CTR checks, revision history, IndexNow updates and automatic rollback behavior.
