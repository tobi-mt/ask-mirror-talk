# Mirror Talk Theme 8.5.0

This release adds conservative, auditable SEO automation for published posts and pages.

- Automatically repairs a definitively broken internal link only when an existing managed redirect or one unique WordPress old-slug record proves the replacement.
- Never guesses replacements for broken external links.
- Creates normal WordPress revisions for repaired content, logs every repair and queues the changed source URL for IndexNow.
- Automatically fills missing search descriptions from existing editorial copy without overwriting manually supplied metadata or manually locked content.
- Extends evidence-led focus-keyword discovery and opportunity reporting to public pages as well as posts.
- Suggests specific relevant internal links without silently inserting links into editorial prose.
- Adds a Safe automation history to Mirror Talk SEO.
- Retains the Google sitemap transport correction, accurate link-health classification and all guarded-learning protections from 8.4.3.
