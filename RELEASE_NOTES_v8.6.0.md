# Mirror Talk Theme 8.6.0

Automatic editorial formatting and production-verification release.

- Adds a non-destructive presentation normalizer for all standard WordPress posts and pages.
- Gives legacy Classic Editor content and modern Gutenberg blocks one consistent responsive rhythm.
- Normalizes headings, paragraphs, lists, quotations, media, embeds, tables, code, forms and captions.
- Prevents body-level H1 duplication on posts while leaving the stored article untouched.
- Makes wide media, long links, code and tables safe on narrow screens.
- Stacks multi-column and media/text blocks cleanly on mobile.
- Removes only genuinely empty legacy paragraphs that create accidental whitespace.
- Supports an explicit `<!-- mirror-talk:preserve-format -->` opt-out for intentionally bespoke documents.
- Includes the 8.5.1 duplicate-page-H1 prevention and cleaner final Core Web Vitals collection.
