# Mirror Talk Theme 8.7.0

Knowledge, editorial intelligence and continuous-quality release.

## Intelligent content command centre

- Joins verified Google and Bing search observations with consented page engagement, podcast starts/completions, conversions, internal search demand and AI referral/citation observations.
- Produces a short evidence-ranked action queue with priority score, recommendation, evidence and expected impact.
- Detects missing topic coverage without manufacturing keyword pages.
- Retains the existing guarded SEO experiment system: no URL changes, one search-title variable, minimum evidence, audit history and rollback.

## Podcast knowledge graph and citation-ready pages

- Creates a public knowledge graph of episodes, guests, topics, questions, quotations, key moments, transcripts and cited resources.
- Adds a protected editorial metadata panel to posts and pages.
- Never guesses credentials, quotations or sources; unverifiable fields remain unpublished.
- Adds citation briefs, verified transcript links, key questions, timestamped ideas, sources, reviewer and correction information to episode pages when available.
- Enriches PodcastEpisode schema only with explicit or existing public editorial facts.
- Adds semantically related conversations and a transparent, consent-dependent local continuation history.

## Continuous quality guardian

- Runs daily and can be refreshed manually in Mirror Talk Intelligence.
- Checks broken links and embeds, visuals, duplicate headings, thin and stale content, orphan pages, schema encoding, accessibility attributes, mobile overflow, declining search visibility, poor field performance and critical runtime surfaces.
- Reuses the established deterministic link repair and media-alt repair systems before reporting editorial decisions.
- Adds a standalone local/remote release gate for core templates, responsive behavior, focus visibility, target sizes and critical public routes.

## Trust, privacy and accessibility

- Creates managed Editorial Standards and Corrections pages without overwriting existing pages.
- Adds both policies to the global footer.
- Adds verified reviewer, review-date and correction-history fields.
- Captures consented internal-site searches only after email, phone and URL redaction.
- Never stores private Ask Mirror Talk questions or reflection text in WordPress intelligence.
- Excludes sensitive inferred themes from personalisation and keeps reading history in the visitor's browser.
- Adds permanent WCAG 2.2 focus, target-size and forced-colour guardrails.

## Data interfaces

- Public read-only knowledge graph: `/wp-json/mirror-talk/v1/knowledge-graph`
- Authorized citation-monitor import/read API: `/wp-json/mirror-talk/v1/ai-citations`
- Intelligence database schema upgraded to `1.2.0`.
