# Mirror Talk 8.9.1

This corrective release tightens the Automatic Editorial Composer after the production audit of 8.9.0.

- Derives provisional focus phrases from the article's complete subject phrase rather than a frequently repeated single name or word.
- Prefers a complete title clause before applying character-limit truncation.
- Keeps extracted takeaway sentences intact so editorial meaning is not cut mid-thought.
- Advances the Composer processing version so previously processed content is safely recomposed with the corrected rules.
- Preserves manual SEO fields, quotations, transcripts, embeds, factual content, URLs, revision history, and per-decision rollback controls.
