# Mirror Talk Atmospheric Art Direction

This collection is decorative rather than informational. It is designed to make the experience feel calm, emotionally safe and recognisably Mirror Talk without using synthetic people, literal wellness imagery, medical symbols or text baked into artwork.

## Deployment rules

- Keep all artwork decorative (`aria-hidden="true"` or CSS backgrounds); meaningful page content remains HTML.
- Preserve strong text contrast with the supplied CSS overlays.
- Serve AVIF first with optimized JPEG fallbacks.
- Use the 900/1000 px variants on narrow screens and the 1600/1800 px variants on wider layouts.
- Do not place emergency, privacy or health guidance inside image files.
- Master PNG files are stored in `artwork/source/`; deployment files are stored in `wordpress/astra-child/assets/art/`.
