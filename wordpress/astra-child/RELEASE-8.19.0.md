# Mirror Talk 8.19.0

## Engagement-led Editorial Composer

- Enables the governed Story Studio experience by default for posts that have never received an explicit editor choice. Existing opt-outs remain respected.
- Matches a recent RSS episode to the article title when confidence is sufficient and otherwise uses the latest verified episode.
- Prefers a YouTube URL already present in the source before using the latest channel video.
- Adds accessible, linked on-page navigation from real section headings.
- Uses question-led headings only when a document lacks useful structure; transcripts, quotations, embeds and stored source content remain untouched.
- Prioritises evidence-backed internal-link opportunities before related-archive fallbacks.
- Defers podcast media loading until the reader interacts, and loads YouTube only after an explicit play action.
- Records Composer navigation and CTA interactions in Mirror Talk Intelligence so editorial impact can be measured.
- Exposes every Composer decision in the editor report with individual disable/enable controls, history and restore support.

Activation schedules a guarded background re-analysis in batches of ten. Public enhancements are server-rendered, so readers and crawlers receive the same document without requiring editor approval.
