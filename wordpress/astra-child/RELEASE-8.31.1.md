# Mirror Talk 8.31.1 — Source Video Priority

- Makes a valid YouTube URL in the current post or page body the strongest document-specific video signal.
- Prevents stale video values saved by historical fallback releases from overriding the conversation's actual video.
- Retains the Story Studio URL as the next source when no video appears in the content.
- Keeps legacy Elementor detection and the latest-channel fallback as progressively lower-priority sources.
